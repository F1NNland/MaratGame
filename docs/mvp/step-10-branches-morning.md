# Шаг 09 — Утренние ветки (минимум)

## Цель
По **одному осмысленному выбору** на ветку + эффект на статы/флаг, возврат в холл.

## Зависимости
**Шаг 08** — навигация работает.

## Референсы
- [SPEC.md](../SPEC.md) — ветки «Столовая», «Лифты» (по 1 варианту)
- [ASSETS.md](../ASSETS.md) — фоны Столовая; портреты в `Люди/` для диалога (опционально)

## Контент (минимум)

### Столовая (`canteen_entry`)
- Фон: Столовая
- Текст: завтрак, запах кофе (1–2 предложения)
- Выборы (2): «Сесть к Козлихину» / «Взять кофе с собой»
  - Козлихин: +флаг `met_kozlikhin`, +5 Respect (пример)
  - Кофе: +5 Calm
- → «В холл»

### Лифты (`elevator_entry`)
- Выбор: «Заговорить с Ноздриковым» / «Читать сообщения»
  - Ноздриков: флаг `met_nozdrikov`
- → «В холл»

### Кабинет (`cabinet_entry`)
- Текст: стол, 43 письма (кратко)
- Один выбор: «Пойти к Алевтине» → узел `alevtina_tease` (короткий диалог) → «В холл»
- Портрет: `Екатерина.jpg` в боковой панели (если есть PortraitImage)

## Не делать
- Все 3 варианта в столовой/лифте из ТЗ
- Туалет, планерка
