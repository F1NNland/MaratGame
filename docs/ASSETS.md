## Использование в Unity (когда дойдём до UI)

1. Texture Type: **Sprite (2D and UI)** или **Default** для полноэкранного фона.
2. Фоны: `Image` на Canvas, `preserveAspect`, смена по `locationId` в `StoryRunner`.
3. Портреты: боковая панель диалога; один файл на персонажа, позы позже.
4. Несколько jpg в одной папке — случайный/первый кадр или выбор по `variant` в узле сценария.
