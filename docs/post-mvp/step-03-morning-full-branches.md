# Шаг 03 — Полные ветки утра

## Цель
Довести утренний блок до полного ТЗ: содержательные диалоги в столовой и лифтах (по 3 варианта).

## Зависимости
- [step-02-engine-stats-media.md](step-02-engine-stats-media.md)

## Сделать

### Столовая (`canteen`)
- Реализовать 3 варианта из SPEC:
  1. Сесть к Козлихину.
  2. Сесть одному.
  3. Кофе с собой.
- Для каждого варианта добавить 2-4 узла диалога, а не одноэкранную реплику.
- Добавить флаги взаимодействий (пример: `met_kozlikhin_breakfast`, `ate_alone_reflection`, `coffee_to_go`).
- Привязать изменения статов (`Respect`, `Calm`, при необходимости `Chaos`).

### Лифты (`elevator`)
- Реализовать 3 варианта из SPEC:
  1. Разговор с Ноздриковым.
  2. Чтение сообщений.
  3. Случайный этаж.
- Включить информацию о КРРБ/маршрутах и дополнительные флаги (пример: `met_nozdrikov_route`, `random_floor_event`).

### Навигация и UX
- Сохранить текущую логику направления ← ↑ →.
- После завершения каждой ветки возвращать игрока в `hall_hub` без soft-lock.
- Убедиться, что для открытия событий дальше используются именно сюжетные выборы, а не клики по стрелкам.

### Контент setup
- Добавить editor setup-команду "Setup Full Morning Branches".
- Новые узлы добавлять в базу аккуратно, без удаления существующих.

## Не делать
- Не переходить в глубину главы 2 (кроме связующих флагов).
- Не делать полную финальную режиссуру медиа.

## Критерии готовности
- [ ] В столовой доступны 3 самостоятельные ветки с несколькими узлами диалога.
- [ ] В лифтах доступны 3 самостоятельные ветки с несколькими узлами диалога.
- [ ] Флаги и статы меняются в соответствии с выбранными вариантами.
- [ ] Любой путь корректно возвращает игрока в hub.

## Unity
- В Play Mode пройти все 6 вариантов утра.
- Зафиксировать итоговые флаги/статы в логах.
- Проверить отсутствие ошибок в `get_console_logs`.

Нужно реализовать полные ветки утра по SPEC: столовая и лифты по 3 варианта, с флагами и статами.
