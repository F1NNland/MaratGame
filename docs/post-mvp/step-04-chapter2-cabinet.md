## Сделать

### Вход в главу 2
- Создать входной узел `chapter2_cabinet_intro` после моста из шага 01.
- Обновить время/блок дня и заголовок главы.

### Четыре выбора кабинета
1. **Почта** — деловой путь:
   - реплика про 43 письма;
   - рост `Respect`;
   - снижение `Chaos` или повышение (по выбранной трактовке из ТЗ) фиксировать явно.
2. **К Алевтине**:
   - диалог с уточнением по встречам/КРРБ;
   - постановка флага для главы 3-4.
3. **5 минут в туалет**:
   - переход в локацию `toilet_intro`;
   - без обрыва основного сюжета.
4. **Встреча 35.44**:
   - вход в мини-сюжет "Не то совещание" (пока минимум как отдельная ветка/placeholder).

### Игровая связность
- Каждая ветка должна иметь возврат в основной поток дня.
- Вести счетчик решений по сюжетным выборам.
- Не допускать dead-end узлов без выхода.

- Добавить editor setup для контента главы 2.
