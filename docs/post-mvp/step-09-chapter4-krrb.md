# Шаг 09 — Глава 4: КРРБ/УК

## Цель
Реализовать блок КРРБ/УК: выбор места, разная реакция окружения и переход в вечер.

## Зависимости
- [step-07-ministory-help-employee.md](step-07-ministory-help-employee.md)
- [step-08-chapter3-planerka.md](step-08-chapter3-planerka.md)

## Сделать

### Структура сцены
- Добавить входной узел `krrb_intro`.
- Реализовать выбор места:
  - рядом с Алевтиной;
  - рядом с Козлихиным;
  - в конце зала.

### Реакции и контекст
- Для каждого места сделать отдельный набор узлов (минимум 2-3 реплики и последствия).
- Учитывать предыдущие флаги:
  - встреча с Козлихиным/Ноздриковым утром;
  - стиль поведения на планерке;
  - флаги мини-сюжетов.

### Эффекты
- Применять изменения к `Respect/Calm/Chaos`.
- Выставлять флаги, влияющие на вечерний финал (например, `high_social_presence`).

### Завершение главы
- Все ветки КРРБ должны сходиться в узел `evening_intro`.
- Обновить время/период на "Вечер".

## Не делать
- Не финализировать здесь "Большое поздравление".
- Не пытаться полностью завершить релизную полировку.

## Критерии готовности
- [ ] В КРРБ доступны 3 варианта рассадки.
- [ ] Каждая ветка имеет различимые последствия.
- [ ] Все ветки сходятся в `evening_intro`.
- [ ] Нет ошибок при переходе из КРРБ в вечер.

## Unity
- Пройти все 3 ветки КРРБ.
- Проверить влияние ранее накопленных флагов.
