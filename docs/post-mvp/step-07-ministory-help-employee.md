# Шаг 07 — Мини-сюжет "Помочь сотруднику"

## Цель
Реализовать мини-сюжет из ТЗ: помощь сотруднику в туалете, с возвратом в основной поток.

## Зависимости
- [step-06-ministory-framework.md](step-06-ministory-framework.md)

## Сделать

### Контент мини-сюжета
- Создать узлы мини-сюжета:
  - вход из `toilet_middle_stall`;
  - диалог/реакция;
  - выбор действий игрока (минимум 2 варианта);
  - выход обратно в туалет (`toilet_intro` или `toilet_after_ministory`).
- Сохранить тональность без наказания: любой выбор корректный.

### Эффекты
- Добавить флаги результатов (пример: `helped_employee`, `handled_delicately`).
- Изменить статы умеренно (`Respect`, `Calm`, опционально `Chaos`).

### UI и медиа
- При наличии использовать `mediaSlot` для иллюстрации сцены.
- Проверить, что сцена корректно отрабатывает в обычном диалоговом UI.

## Не делать
- Не добавлять unrelated мини-сюжеты.
- Не внедрять здесь вечернюю развязку.

## Критерии готовности
- [ ] Мини-сюжет доступен из ветки туалета.
- [ ] Сюжет имеет минимум один выбор и корректные эффекты.
- [ ] После завершения есть возврат в основной поток.
- [ ] Нет ошибок в Play Mode/Console.

## Unity
- Пройти мини-сюжет двумя разными вариантами.
- Проверить выставление флагов в состоянии.

## Промпт
```text
MaratGame: выполни только docs/post-mvp/step-07-ministory-help-employee.md.
Подключи мини-сюжет "Помочь сотруднику" на базе каркаса из step-06.
```
