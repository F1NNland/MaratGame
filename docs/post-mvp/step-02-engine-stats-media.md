# Шаг 02 — Engine, Chaos, Media

## Цель
Расширить ядро данных и StoryEngine под полный ТЗ: скрытый стат `Chaos`, условия показа, медиа-слоты, блоки дня.

## Зависимости
- [step-01-full-day-bridge.md](step-01-full-day-bridge.md)

## Сделать

### Core и Data
- Добавить `Chaos` в core-статы:
  - `StatType`, `GameStats`, `GameState`, `StatChangeEntry`.
- Оставить `Chaos` скрытым от базового HUD (пока без обязательного визуального индикатора).
- Добавить модель времени дня:
  - enum/идентификатор блока (`Morning`, `BeforeMeeting`, `AfterMeeting`, `KrrbUk`, `Evening`, `Final`).

### Story model
- Расширить `StoryNodeData`:
  - `requiredFlags` (узел доступен при выполнении флагов);
  - `requiredStats` (минимальные/максимальные пороги, если используются);
  - `mediaSlot` (`none`, `image`, `gif`, `video`) и `mediaPath`.
- Расширить `StoryChoice`:
  - опциональные условия доступности;
  - опциональный текст/причина недоступности (для UI).

### StoryEngine
- На `LoadNode` проверять условия узла и давать понятную ошибку при недоступности.
- При построении выбора отдавать только доступные опции или помечать недоступные.
- Сохранить обратную совместимость для старых узлов без новых полей.

### Presentation hooks
- Подготовить `GameUIController` к медиа-слотам:
  - image/gif/video пока может быть placeholder, но pipeline должен быть готов.
- В HUD отображать текущий блок дня (не только "Утро").

### Тесты
- Добавить/обновить smoke тесты:
  - применение `Chaos`;
  - условные выборы;
  - поведение медиа-слотов без реальных ассетов.

## Не делать
- Не подключать весь финальный арт в этом шаге.
- Не реализовывать полноценный video player UI во всех сценах (только интерфейс данных и базовый хук).

## Критерии готовности
- [ ] `Chaos` учитывается в состоянии и эффектах выбора/узла.
- [ ] Условия на узлы и выборы работают без поломки MVP контента.
- [ ] Узлы с `mediaSlot` рендерятся хотя бы в fallback-режиме.
- [ ] Существующие утренние шаги проходят без регрессий.

## Unity
- Сгенерировать тестовые узлы с условиями и `mediaSlot`.
- Прогнать Play Mode + `get_console_logs`.
- Прогнать editor smoke для Story/GameState.
