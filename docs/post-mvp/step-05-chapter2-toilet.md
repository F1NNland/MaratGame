# Шаг 05 — Глава 2: туалет

## Цель
Сделать отдельную играбельную локацию "Туалет" с 4 вариантами из ТЗ.

## Зависимости
- [step-04-chapter2-cabinet.md](step-04-chapter2-cabinet.md)

## Сделать

### Узлы туалета
- Создать цепочку узлов:
  - `toilet_intro`
  - `toilet_wash_face`
  - `toilet_phone_messages`
  - `toilet_silence_monologue`
  - `toilet_middle_stall`
- Переход из кабинета (`5 минут в туалет`) должен приводить в `toilet_intro`.

### Варианты действий
1. **Умыться** — +Calm, опциональный media slot gif.
2. **Телефон** — показать пакет новых входящих (15 сообщений в логике/контенте).
3. **Тишина** — внутренний монолог и флаг для вечерней рефлексивной сцены.
4. **Средняя кабинка** — вход в мини-сюжет "Помочь сотруднику" (пока точка входа).

### UX и возвраты
- Любой путь не должен блокировать игрока.
- Минимум один явный путь возврата в основной поток дня.
- Использовать отдельный `locationId: toilet` для фона и label.

## Не делать
- Не завершать в этом шаге мини-сюжет "Помочь сотруднику" (только вход).
- Не реализовывать финальные видео/арт сцены.

## Критерии готовности
- [ ] Из кабинета есть переход в туалет.
- [ ] В туалете доступны 4 действия.
- [ ] Действия меняют флаги/статы и ведут в корректные узлы.
- [ ] Есть стабильный возврат в основной сценарий.

## Unity
- Play Mode: пройти каждый из 4 вариантов.
- Проверить `get_console_logs` и отсутствие null refs.
