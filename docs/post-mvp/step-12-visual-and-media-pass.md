# Шаг 12 — Visual and Media Pass

## Цель
Подключить визуальные материалы по локациям и узлам: фоны, портреты, gif/video.

## Зависимости
- [step-02-engine-stats-media.md](step-02-engine-stats-media.md)

## Сделать

### Фоны и локации
- Для ключевых `locationId` назначить реальные фоны из [docs/ASSETS.md](../ASSETS.md):
  - hall, canteen, elevator, cabinet, toilet, planerka, krrb, evening.
- Обеспечить плавную смену через `UiTweens.CrossFadeImage`.

### Портреты персонажей
- Подключить портреты минимум для:
  - Алевтина;
  - Козлихин;
  - Ноздриков.
- Сопоставление делать по `portraitCharacterId`.

### MediaSlot
- Реализовать обработку:
  - `image` -> статичное изображение;
  - `gif` -> либо анимированный placeholder/плейбек через доступный компонент;
  - `video` -> VideoPlayer overlay с безопасным fallback.
- Для отсутствующих файлов не падать, а показывать placeholder и лог-предупреждение.

### Технические проверки
- Убедиться, что все TMP тексты остаются читаемыми поверх фонов.
- Проверить, что overlay медиа не блокирует UI навсегда.

## Не делать
- Не выполнять финальную color grading и сложный постпроцесс.
- Не хранить тяжелые видео в git, если это нарушает текущий workflow.

## Критерии готовности
- [ ] Для всех ключевых локаций есть фон и переход без мерцания.
- [ ] Портреты персонажей отображаются в диалогах.
- [ ] Узлы с mediaSlot отображаются корректно или через fallback.
- [ ] Нет soft-lock после показа медиа.

## Unity
- Пройти набор узлов по каждой локации.
- Проверить gif/video узлы и возврат в обычный UI.

## Промпт
```text
MaratGame: выполни только docs/post-mvp/step-12-visual-and-media-pass.md.
Подключи фоны, портреты и mediaSlot (image/gif/video) для полного дня.
```
