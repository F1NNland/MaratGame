# Шаг 01 — Full Day Bridge

> **Релиз:** утренний `ending_screen` удалён. Поток: `birthday_scene` → `pre_planerka_bridge` → глава 2.

## Цель
Убрать эффект "день закончился сразу после утра" и сделать безопасный мост к блоку **До планерки**.

## Зависимости
- MVP шаги 01-12 завершены.

## Сделать

### Сценарный поток
- Сохранить текущую утреннюю арку (холл, телефон, ветки утра).
- После `birthday_scene` вести напрямую в узел-мост `pre_planerka_bridge` (без MVP-экрана итогов утра).
- Новый узел должен:
  - обновлять время;
  - переключать главу/период на "До планерки";
  - вести в первый узел главы 2 (`chapter2_cabinet_intro`).

### Логика UI
- В `EndingUI` сохранить показ итогов утра, но изменить действие продолжения:
  - отдельная кнопка "Продолжить день" или авто-переход после подтверждения;
  - "Сыграть ещё раз" оставить для отладки только как вторую кнопку.
- Убедиться, что `GameBootstrap.ResetGame()` не вызывается при обычном продолжении дня.

### Контент и setup
- Добавить editor setup-команду для создания узла-моста и главы 2 entry в StoryDatabase.
- Не менять `startNodeId` у базы, чтобы MVP smoke оставался валиден.

## Не делать
