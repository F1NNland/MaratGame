# Шаг 10 — Вечер и большое поздравление

## Цель
Собрать вечерний блок и финал полного дня, включая условную ветку "Большое поздравление".

## Зависимости
- [step-09-chapter4-krrb.md](step-09-chapter4-krrb.md)

## Сделать

### Вечерний блок
- Добавить узлы `evening_intro` и `evening_bank_empty`.
- Показать смену атмосферы: банк пустеет, рабочий день завершается.
- Включить кнопку/выбор "А что дальше?".

### Большое поздравление
- Реализовать условный переход в `big_congratulation`:
  - условие: "много общался" (набор флагов и/или пороги статов);
  - fallback: базовая хорошая концовка, если условие не набрано.
- Сохранить правило ТЗ: не game over, все исходы положительные.

### Финальные итоги
- Обновить итоговый экран:
  - `Respect`, `Calm`, `Chaos` (скрытый можно показать только в debug);
  - количество решений;
  - ключевые достижения по флагам.
- Добавить действия:
  - "Сыграть еще раз";
  - "В главное меню".

## Не делать
- Не добавлять отдельные альтернативные "плохие" концовки.
- Не уходить в технический release/deploy (это следующий шаг).

## Критерии готовности
- [ ] После КРРБ доступен вечерний блок.
- [ ] Ветка "Большое поздравление" корректно открывается по условиям.
- [ ] В любом случае игрок получает завершенный позитивный финал.
- [ ] Replay/reset работают стабильно.

## Unity
- Пройти минимум 2 траектории: с `big_congratulation` и без.
- Проверить консоль и корректность итогового экрана.

## Промпт
```text
MaratGame: выполни только docs/post-mvp/step-10-evening-big-congratulation.md.
Собери вечерний блок и условную ветку большого поздравления без game over.
```
