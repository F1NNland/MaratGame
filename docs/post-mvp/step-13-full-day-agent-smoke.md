# Шаг 13 — Full Day Agent Smoke

## Цель
Собрать автоматизированный smoke полного дня через Unity MCP и Agent bridge.

## Зависимости
- [step-10-evening-big-congratulation.md](step-10-evening-big-congratulation.md)

## Сделать

### Чеклист сценарного smoke
- Прогон минимум одного полного пути:
  - утро -> глава 2 -> планерка -> КРРБ -> вечер -> финал.
- Прогон альтернативного пути (другие ключевые выборы).
- Проверка, что оба пути заканчиваются валидным позитивным финалом.

### Agent bridge
- Обновить `AgentPlayBridge` под новые действия/узлы полного дня.
- Добавить понятные `actionId` для новых экранов и выборов.
- Убедиться, что bridge возвращает актуальные статы, флаги и node id.

### Автотесты
- Добавить editor/runtime smoke сценарии:
  - no-soft-lock assert;
  - переходы между блоками дня;
  - условие большого поздравления.
- Закрепить smoke-команды в одном месте (menu item или helper класс).

### Документация
- Обновить [docs/AGENT_PLAY.md](../AGENT_PLAY.md) для нового полного потока.

## Не делать
- Не строить полный CI pipeline в этом шаге (только smoke внутри проекта).
- Не смешивать с релизной упаковкой.

## Критерии готовности
- [ ] Автопрохождение полного дня работает минимум для 2 маршрутов.
- [ ] Bridge поддерживает новые узлы и действия.
- [ ] Логи smoke не содержат критических ошибок.
- [ ] `AGENT_PLAY.md` отражает актуальный путь.

## Unity
- `enter_play_mode` -> `game_get_play_state`/`game_perform_action` или эквивалент через bridge.
- Зафиксировать финальные статы и узел финала для каждого маршрута.

## Промпт
```text
MaratGame: выполни только docs/post-mvp/step-13-full-day-agent-smoke.md.
Нужно обновить AgentPlayBridge и собрать smoke полного дня минимум по двум маршрутам.
```
